Install Ma

The full version with Screen Time, for your own iPhone.

Install

Version __VERSION__ · Build __BUILD__

  1. Open this page in Safari on your iPhone and tap Install.
  2. Go to the home screen and wait until Ma has finished loading.
  3. The first time only: Settings, Privacy & Security, Developer Mode, switch it on and restart.
  4. Open Ma and allow Screen Time.

This build only installs on registered devices. If the install stalls, delete the TestFlight copy of Ma first.
